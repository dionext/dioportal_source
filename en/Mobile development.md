
# React Native

https://reactnative.dev/

"React Native" (often what "native react" refers to) is an open-source framework by Meta that allows developers to build mobile, web, and desktop applications for multiple platforms using JavaScript and the React framework. It uses native platform components, so apps look and feel like other native apps, providing a consistent and efficient developer experience for building cross-platform applications.  
Key Aspects
- Cross-Platform Development: Write one codebase in JavaScript and deploy it to Android, iOS, Windows, and other platforms, rather than building separate apps for each. 
- Native Performance and UI: React Native components render to native platform UI building blocks, ensuring that the app looks and performs like a truly native application. 
- JavaScript and React: Leverage your existing knowledge of JavaScript and the React library to build mobile applications. 
- Developer Efficiency: The "learn once, write anywhere" philosophy streamlines the development process, allowing for efficient creation of high-quality applications across various platforms.

## Expo
https://expo.dev/ 
https://expo.dev/go   https://expo.dev/orbit  (for android emulator) 

Expo is a production-grade React Native Framework. Expo provides developer tooling that makes developing apps easier, such as file-based routing, a standard library of native modules, and much more.

~~~
npx create-expo-app@latest --template
~~~
Navigation (TypeScript) 

To run your project, navigate to the directory and run one of the following npm commands.

- cd D:\projects\my-react-native-app
- npm run android
- npm run ios # you need to use macOS to build the iOS project - use the Expo app if you need to do iOS development without a Mac
- npm run web
